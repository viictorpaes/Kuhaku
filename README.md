# Kuhaku

Monorepo com duas aplicações separadas:

- `frontend`: React + TypeScript + Vite
- `backend`: NestJS + TypeScript

## Estrutura

```text
frontend/
backend/
```

## Scripts

- `npm run dev:frontend`
- `npm run dev:backend`
- `npm run build`
- `npm run typecheck`
- `npm run docker:up`
- `npm run docker:down`

## Próximo passo

Suba tudo com `npm run docker:up`.
